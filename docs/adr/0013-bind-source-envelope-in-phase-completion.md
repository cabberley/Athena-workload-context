# ADR 0013: Bind the trusted source envelope in phase completion

- **Status:** Proposed
- **Date:** 2026-08-28

## Context

The phase Job validates each evidence snapshot with the exact trusted MCP source-envelope resolver,
but the immutable completion set previously retained only the evaluation result, snapshot, ARGUS
presentation, and presentation attestation. The external operator could therefore re-check artifact
hashes and signatures without re-checking the snapshot's digest-covered source pointers against the
exact MCP envelope.

## Decision

Require each operational phase to persist the exact canonical source envelope as a fifth create-only
artifact. Its immutable Blob name, version, and byte digest are included in
`athena.operationalPhaseCompletionIndex.v2`.

The external operator requires the v2 index, reads the exact version-pinned envelope, and supplies a
resolver bound to the indexed attempt, envelope kind, and snapshot digest when it calls
`EvidenceSnapshot.validate_for_evaluation`.

The completion-index schema is versioned from v1 to v2 rather than assigning two incompatible
artifact sets to one schema identifier.

## Consequences

- Missing, substituted, or digest-mismatched source envelopes fail closed.
- Source-response JSON pointers are re-evaluated at the external operator boundary.
- Existing v1 completion indexes remain identifiable as the older four-artifact contract, but they
  cannot satisfy the strengthened operator verification and must be regenerated by a v2 phase Job.
- The source envelope remains in the private artifact container and is not added to handoff or
  console output.

## Alternatives considered

### Continue trusting the phase Job's earlier snapshot validation

Rejected because the external operator must independently verify the immutable artifacts it accepts.

### Add the fifth artifact without changing the schema version

Rejected because old and new readers would assign incompatible shapes to the same v1 identifier.

## Validation

Targeted tests prove successful exact-version reads and fail closed when the source-envelope artifact
is absent or replaced with a different phase's envelope. Ruff and mypy validate the changed Python
surfaces.
