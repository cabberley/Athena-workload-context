## Editing rules

1. Use real captures only when they contain synthetic-safe data and no credentials or unrestricted
   logs.
2. Preserve the exact sequence: healthy, faulted, impact, evidence, guidance, recovered.
3. Crop browser chrome unless the URL and environment are approved for display.
4. Do not imply Athena performed remediation.
5. Keep measured values visibly labelled **Measured** and projections labelled **Target**.
6. Avoid architecture diagrams in this version unless a capture fails and a five-second fallback is
   required.
