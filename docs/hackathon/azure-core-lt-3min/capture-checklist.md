# Azure Core LT video capture checklist

## Required captures

| ID | Capture | Leadership evidence | Placeholder scene |
|---|---|---|---|
| LT-01 | Context Studio overview | Workload identity, environment, ownership, objectives, and version status | 3 or 7 |
| LT-02 | Relationship separation | Declared, observed, inferred, and exception relationships visibly distinct | 3 |
| LT-03 | Three-profile proof | Same topology and code path; different correct judgments | 4 |
| LT-04 | Healthy baseline | Workload and context version bound to current evidence | 5 |
| LT-05 | Fault and contextual impact montage | Separate approved views of affected role, contained web-tier impact, operator attention, and evidence lineage | 5 |
| LT-06 | Exact causality | Network or NSG evidence supporting the leading hypothesis | 6 |
| LT-07 | Evidence details | Supporting, contradicting, missing, and confidence fields | 6 |
| LT-08 | Governance flow | Draft, review, approval, publish, or version comparison | 7 |
| LT-09 | Guidance state | Verified guidance when available, or an explicit guidance-unavailable state, plus the human decision boundary | 7 |
| LT-10 | Verified recovery | Recovery state with incident and context continuity | 5 |

## Capture safety

- [ ] Synthetic workload data only.
- [ ] Microsoft Azure, Azure MCP, and Epic are the only currently approved named products.
- [ ] No customer, employee, tenant, subscription, identity, endpoint, or credential details.
- [ ] No unrestricted log bodies.
- [ ] No claim that Athena performs remediation.
- [ ] Architecture visuals contain conceptual names rather than deployed resource identifiers.

## Final review

- [ ] 1920 x 1080, 30 fps, silent H.264 MP4.
- [ ] No longer than 3:00.
- [ ] Pilot candidate, time box, evidence owner, and outcome are approved.
- [ ] Every metric is labelled measured or target.
- [ ] Captions and narration transcript match the final visual edit.

## Fallback gate

- [ ] Use the verified standalone lifecycle if the latest incident release is unavailable.
- [ ] Use the packaged golden proof if the three-profile experience is not available in the web UI.
- [ ] Retain a conceptual governance visual if Context Studio is not capture-ready.
- [ ] Show explicit guidance unavailability if the verified guidance feed is not deployed.
- [ ] Do not composite fields from separate surfaces into a screen that the product does not have.
