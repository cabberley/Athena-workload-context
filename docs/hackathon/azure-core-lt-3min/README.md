# Azure Core - Specialized Engineering LT pitch

**Audience:** Azure Core - Specialized Engineering leadership team

**Maximum duration:** 3:00

**Rendered target:** 2:56

**Desired outcome:** sponsorship, integration support, product data, platform adoption, and
continued investment

This version positions Athena as a reusable Azure workload-intelligence capability rather than a
single incident demonstration. It retains the live proof but gives leadership enough product and
architecture context to evaluate a pilot.

The current end-to-end web-node scenario demonstrates a contained web-tier impact. Broader
workload impact is a capability to validate across additional scenarios, not a claim made by this
video.
